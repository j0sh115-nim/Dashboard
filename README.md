# Creative HQ — Personal Dashboard

A responsive personal workspace for content creation, college assignments, acting/script practice, music projects and scheduling.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a **public** GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.

Your site will appear at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Important security note
This is a front-end prototype. Demo credentials are visible in `script.js` and do not provide real security. Do not use this login to protect private information. For a real private dashboard, connect an authentication provider such as Firebase Authentication or Supabase Auth and enforce permissions server-side.
